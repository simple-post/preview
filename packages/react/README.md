# `@simple-post/preview-react`

The React adapter for [`@simple-post/preview`](https://github.com/simple-post/preview#readme).

```tsx
import { PostPreview } from "@simple-post/preview-react";

<PostPreview theme="light" data={{ platform: "x", account: { platform: "x", username: "ada" }, message: "Hello!" }} />;
```

The `theme` prop accepts `"dark"` or `"light"`; dark is the default.
